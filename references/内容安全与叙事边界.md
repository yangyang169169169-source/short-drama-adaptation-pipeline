# 内容安全与叙事边界

本文件用于底本风险审阅、大纲映射、正式写作和分镜化。判断时同时检查 **行为目的、当事人行为能力、叙事立场和行为后果**，不得只凭“强吻”“壁咚”“上下级”“打斗”等关键词机械删戏。

## 执行原则：先报告，等用户决定

- 下文分级和条件是审阅依据，不是自动删改指令，也不代表具体平台已经判定违规。区分明确问题、依赖语境的疑点和风格偏好；反派作恶、未遂威胁、既往背景事件与镜头直接展示分别判断。
- 每条只列：**编号与分级、集数/场次/行号、原文依据、具体风险与上下文、判断把握、对原看点的影响、可选处理、确认状态**。证据不够写“需确认”，不要把推测写成事实；可选处理须包含是否可保留及其理由，不预设必须替换。
- 未经用户确认，不删除、弱化或替换原桥段，不补写同意、停止动作、道歉、HR或权力回避来强行通过检查。风险意见放在内部清单，不写进正式剧本作为新剧情。
- 用户确认后只执行指定范围，所有Agent读取同一份确认记录；新增问题另行报告。真实工具或适用内容限制阻止某项执行时，说明具体限制与可行选项，不用另一套剧情静默代替，其他可执行工作继续。

## P0：高风险待确认

以下为优先审阅的情形；是否成立须给出原文和语境证据，不能仅凭题材或关键词命中：

1. 明确拒绝、恐惧、挣扎或僵住后，仍强迫性行为、性接触或脱衣。
2. 与昏迷、睡眠、重度醉酒或其他无法理解和选择的人发生性行为。
3. 通过下药、催情、催眠、精神控制、魔法、信息素、发情期或诅咒使当事人丧失自主能力后发生性行为。
4. 以工作、晋升、处分、债务、住房、医疗、学业、签证、人身自由或家人安全交换亲密或性行为。
5. 破坏避孕、强迫怀孕或流产、以孩子作为亲密关系的控制工具。
6. 未成年人、年龄不明者或近亲之间的性内容。
7. 私密影像的偷拍、传播、勒索，或以此逼迫亲密关系。
8. 把强迫性行为、性胁迫、长期监禁、跟踪骚扰或家庭暴力包装成爱情，或用“后来相爱”一笔洗白。
9. 断肢、挖眼、虐杀、毁容、长时间殴打或血腥细节展示等残酷伤害。
10. 使用现实仇恨侮辱语、非人化表达，或让叙事认同针对种族、肤色、族裔、国籍、宗教、性别、性倾向、阶级、财富、职业、地域、口音、容貌、体型、年龄或残障群体的伤害。

## P1：需结合语境判断

### 亲密同意底线

- 参与者必须是具备行为能力的成年人，能理解当下行为，并表现出主动、持续、可撤回的意愿。
- 沉默、僵住、未反抗、婚姻关系、过往亲密经历都不等于当次同意；同意接吻不等于同意性行为。
- 酒精只能是情绪催化剂。双方仍须能清晰沟通、理解、选择和记忆；“喝酒前相爱”不能为无行为能力开豁。

### 权力差关系判定顺序

不得看到“老板/助理”“雇主/雇员”“工资”“住房”或“资源支持”就自动要求解除管理关系或增加HR说明。必须按以下顺序判断：

1. 亲密行为是否被明示或暗示为任职、薪酬、晋升、住房、医疗、资源或安全的交换条件？若是，列为P0风险并附证据，等待用户决定。
2. 弱势方拒绝、犹豫或结束关系后，是否会遭到处分、解雇、降薪、赶出住所、封杀或其他报复？若是，列为P0风险并附证据，等待用户决定。
3. 弱势方是否表现出主动选择、持续同意和真实退出空间？若是，不能仅凭身份差推定其被迫。
4. 工资、住房或资源是否在亲密关系之前已经独立确定，且不会因拒绝而撤销？若是，这些支持本身不构成利益交换。
5. 是否属于在读学生与直接任课教师、当前患者与主治医生、被监护/高度依赖者与监护人、直属军事指挥官与下属？重点说明现实依赖、拒绝代价和自主选择；结束直接关系仅是可选建议，不自动写入剧本。

普通职场恋爱只有在剧情实际呈现重大利益冲突、现实依赖或拒绝风险时，才提出第三方决策、管理回避或岗位调整等选项。不得为了形式合规，给双向恋爱强行增加HR、合同或调岗说明；是否调整交用户决定。

**明确停止指令**：在愤怒、争执、离开、恐惧或挣扎语境中，出现“放开”“停下”“别碰我”“Let go”“Stop”等指令后仍继续接触，应报告具体行为和风险；立即停止并留出距离可作为建议，未经确认不自动改写。文本有清楚的玩笑语气和持续双向身体信号时可结合语境判定调情；不能把严肃拒绝解释成欲拒还迎。

**功能性亲吻补充**：接受方可能在事后愤怒、质问、要求道歉或重申界限，但不得自动补写这些反应。功能性亲吻不自动产生恋爱或性同意；契约隐藏终身绑定等重大后果时报告欺骗或信任风险，不擅自增加关系危机剧情。

## P2：项目风格偏好

P2不是普遍道德禁令，而是新创内容的默认风格。底本不符合这些偏好时只列为风格意见，不据此改写；用户明确设定可覆盖，涉及P0疑点另行报告。

1. 核心正面角色默认不因金钱、交易、复仇、晋升或其他非情感原因发生性行为，避免付费情妇、纯交易一夜情等核心爱情设定。
2. 性行为默认建立在可见的双向情感基础之上。
3. 契约婚姻、包办婚姻、假恋爱、禁忌恋和先婚后爱可保留，但契约与婚姻不产生亲密义务。
4. 可保留男性魅力、占有欲、保护欲、身体距离张力和“霸道”视觉表达，但不得剥夺另一方拒绝、离开或改变主意的权利。

## 高风险桥段候选处理（仅供用户选择）

以下不是默认修改方案。用户选择保留、调整呈现或替换后，才在确认范围内执行，并保留原桥段的冲突、情绪、关系和打点；不把所有风险桥段自动改成下表版本。

| 原桥段问题 | 可选调整方式 | 应保留的原剧功能 |
|---|---|---|
| 强迫亲密用来制造拉扯 | 强势靠近 -> 停顿 -> 双向选择，或把亲吻改为中止在最近距离 | 身体张力、人物心态、关系转折 |
| 下药/无意识性行为用来制造误会 | 企图被中止；醒后制造“发生了”的假象；真正亲密改到日后清醒且双向的节点 | 误会、承诺、关系障碍、后续揭秘 |
| 已出现权力换取亲密、拒绝报复或现实依赖胁迫 | 去除交换和报复机制；根据实际风险交由第三方决策、完成管理回避，或结束医疗/教学/监护/直属军事依赖后再推进 | 禁忌感、身份差、风险与选择 |
| 残酷伤害用来制造危险 | 威胁、追逐、短暂制服、抢救、救援或后果化表达 | 危险等级、迫切性、保护/反击爽点 |
| 歧视用来制造羞辱 | 保留反派势利、傲慢和双标，控制用词，让反击针对行为而非身份 | 公开压迫、观众愤怒、身份反转与打脸 |

## 交付前快速检查

1. 风险条目是否有可定位的原文证据、分级理由与用户确认状态？不得以P0清零作为自动改剧目标。
2. P1是否结合目的、同意、依赖、叙事立场和后果判断，而不是因缺少声明就自动补戏？
3. 叙事是否明确区分“角色在作恶”与“作品在认同”？
4. 酒精、药物、魔法、契约或权力差是否破坏了当事人的自主选择？
5. 暴力是否服务于危险、救援和反击，而不是把折磨当成奇观？
6. 歧视是否只属于反派立场，且未使用现实仇恨侮辱语？
7. 已确认的调整是否只发生在授权范围，并保留原剧冲突、情绪、关系、打脸顺序和集尾钩子？未决项是否如实报告而未被擅改？
8. 是否因过度规避而误删了甜宠张力、男性魅力、功能性亲吻、反派压迫、动作救援或打脸结构？
